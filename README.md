# Assistive Voice and Remote Alert System for Immobilized Patients

## 📌 Description
A smart assistive system that helps immobilized patients communicate using simple buttons. The system converts button presses into voice messages and sends instant alerts to caregivers via Telegram.

---

## 🎯 Objective
**To develop a low-cost, user-friendly assistive device that enables partially paralyzed and immobilized patients to communicate using minimal hand or finger movement, ensuring quick and reliable assistance during emergencies.**
---

## ⚙️ Features
- Button-based communication  
- Voice output using Text-to-Speech  
- Instant alerts via Telegram  
- Simple and user-friendly design  
- Low-cost and reliable  

---

## 🛠️ Tools and Technologies Used

- **Arduino**  
  Detects button presses and sends signals to the system.

- **Push Buttons**  
  Used by patients to send predefined messages.

- **Python**  
  Processes input data and controls system operations.

- **Text-to-Speech (TTS)**  
  Converts messages into voice output.

- **Telegram API**  
  Sends alert notifications to caregivers.

- **Serial Communication**  
  Enables communication between Arduino and Python.

---

## 🚀 How It Works
1. Patient presses a button  
2. Arduino detects the input  
3. Data is sent to Python via serial communication  
4. Message is converted into voice output  
5. Alert is sent to caregiver through Telegram  

---

## 📌 Applications
- Hospitals  
- Home care  
- Elderly assistance  
- Disabled support systems
